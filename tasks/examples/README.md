# Task folder requirements

Every task in this project lives in `tasks/<task-name>/` on some branch.

## Completeness bar

A task folder counts as implemented only when it contains at least 5 files and both of the mandatory files are present: docs/task.md and evaluation/main.py. A folder with fewer than 5 files, or with either mandatory file missing, counts as implementing.

## Notes

- Apart from the rules spelled out above, only the existence of files matters.
- Example folders: `sample-complete` (implemented layout) and
  `sample-partial` (still implementing layout).
